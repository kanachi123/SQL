# Триггеры SQL (Northwind) — пошаговый урок

Цель: с нуля объяснить, как писать, тестировать и отлаживать триггеры на базе Northwind (MS SQL Server) на простых, понятных примерах.

Файлы в этом каталоге:
- `trigger.sql` — короткий пошаговый скрипт с инструкциями "с нуля".
- `trigger_examples.sql` — более развёрнутые примеры (аудит, INSTEAD OF, защита удаления и т.п.).

Пререквизиты:
- MS SQL Server или SQL Server Express
- База Northwind установлена в MS SQL Server (обычно `Northwind`). Если нет — скачать/развернуть Northwind и восстановить базу.

1) Быстрый запуск и проверка базы Northwind
```sql
-- Проверить, есть ли база Northwind
SELECT name FROM sys.databases WHERE name LIKE '%Northwind%';

-- Если Northwind есть, перейдите к её использованию
USE NORTHWIND;
GO
```

2) Основной сценарий
    1. Создадим простую таблицу аудита `Orders_Audit`.
    2. Напишем `AFTER` триггер на `Orders`, который записывает INSERT/UPDATE/DELETE.
    3. Напишем `INSTEAD OF INSERT` триггер, который валидирует `ShipCountry`.
    4. Напишем `INSTEAD OF DELETE` триггер, запрещающий удаление отгруженных заказов.

3) Как запускать и проверять
- Откройте `trigger.sql` и выполните блоки по очереди в SSMS (или в другом клиенте).
- После выполнения каждого блока используйте тестовые INSERT/UPDATE/DELETE из `trigger.sql` и `trigger_examples.sql`.

4) Дополнительно
- `trigger_examples.sql` содержит примеры для `Order Details` и обновления сумм, а также команды для просмотра и удаления триггеров.

5) Отладка
- Используйте `SELECT` для просмотра `INSERTED`/`DELETED` внутри триггера или используйте `RAISERROR`/`PRINT` для отладки.
- Для профайлинга используйте SQL Server Profiler или Extended Events.
